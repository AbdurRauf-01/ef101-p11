Privacy Policy

Effective Date: October 30, 2026
Repository: https://github.com/AbdurRauf-01/ef101-fall2026-p11

Overview

This application is designed with absolute privacy in mind. It is a 100% locally hosted, offline application. We believe your data belongs solely to you, which is why the application operates entirely on your device without transmitting data anywhere else.

Key Privacy Commitments

1. No Data Collection or Telemetry

  • Zero Telemetry: We do not collect, track, or aggregate any analytics, telemetry, usage statistics, crash reports, or diagnostic data.
  • No Tracking: There are no third-party trackers, software development kits (SDKs), or advertising frameworks embedded in this application.

2. No User Accounts or Authentication

  • No Sign-Up Required: You do not need to create an account, log in, or provide any personal information (such as your name, email address, or phone number) to use the application.
  • Local Identity: Any preferences or settings you configure are saved locally on your device and are never linked to an identity on a remote server.

3. Local Storage & Processing

  • Device-Bound Data: All data generated, processed, or saved while using this application remains strictly on your local machine or local network environment.
  • No Remote Transmission: The application does not communicate with external servers, cloud providers, or remote databases.

4. Internet Connectivity

  • Offline Operation: The application does not require an active internet connection to function.
  • Network Requests: The application makes zero outbound internet requests during normal operation.

Open Source Transparency

This application is fully open source. You can audit the codebase, inspect the dependencies, or build the application from source yourself by visiting our official GitHub repository:

github.com/AbdurRauf-01/ef101-fall2026-p11

Changes to This Policy

Because the application does not collect data or maintain user contact information, any updates to this Privacy Policy will be reflected directly in the project repository.
